# Defillama Research

Use for protocol TVL, fees, chains, categories, yields and flows. HyperGrok analyses autonomously but never treats analysis as approval to move funds.

## When to use

Use for protocol TVL, fees, chains, categories, yields and flows.

## Procedure

1. Resolve the canonical protocol slug.
2. Run `hypergrok defillama <slug>`.
3. Record TVL denomination, chains and timestamp.
4. Cross-check material public numbers with a second source family.

## Pitfalls

TVL is not revenue, deposits are not net inflows, and free endpoints do not expose every paid metric.

## Verification

Return the live source, observation time, facts, inference, failed gates and one next owner. For execution, include the plan hash, cloid, builder attribution and verified effect.
