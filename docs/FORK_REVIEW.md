## Disposition of other changes

**thysmans/hypergrok-iterated.** Inspected all fifteen changed files across four commits. The command-matching approval hook cannot bind a send to account, network, exact ticket, written standing scope or expiry. A protective-looking comment or a command containing both a stop and an entry can trigger its automatic allow, while external scripts and alternate SDK routes bypass matching. It was rejected. The three strategy playbooks ship trade signals and hardcoded settings outside this desk's scope and leave the public template inventory inconsistent; they were rejected. Its personal daily cadence was not adopted. The account clarification was adapted only as a mode-specific check: one testnet observation does not establish a universal spot/cross collateral model.

**jawndiego/hypergrok-trading-desk.** `codex/harness-foundation` is contained in `codex/always-on-desk-node`; both are contained in `main`; `main` is contained in `codex/testnet-infra-commissioning`. The last branch adds 73 commits beyond fork main. Main changes 526 files and introduces a Python signing/runtime product, transactional stores, MCP services, role-isolated credentials and deployment machinery. The commissioning branch adds routing, VPN, ACL, VM and migration work for that product. These were reviewed for portable controls but not imported as a replacement for the instruction pack. Strategy adapters, signal scanning, systematic grants and return claims remain outside scope. Its monotonic realized-loss budget is a different risk definition and was not substituted for the desk's equity-based daily stop. Fork tests were inspected as design evidence, not executed; this review makes no runtime-readiness claim.

**shadowslayerai/hypergrok-trading-desk.** Inspected `STEAL.md`, `DESK-REVIEW.md` and `DESK-CHANGELOG.md` on both feature branches. Most controls are adaptations of existing HyperGrok features into a Coinbase CFM desk: stressed stops, depth floors, exact ticket ids, protection deadlines, journal review and three-outcome watches. Coinbase contract/margin-window/expiry specifics and another user's account configuration were not transferred. The critique of the native-approval fallback identified a real upstream contradiction and was resolved.
